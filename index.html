About this module

Module 1 of Leo-Law. Covers the ~120 most-used penal provisions mapped between the Indian Penal Code, 1860 and the Bharatiya Nyaya Sanhita, 2023, plus offences that are new in the BNS and those omitted / decriminalised. Works fully offline once opened; install it to your home screen.

Status tags

  • Mapped — substantially the same offence, renumbered.
  • Renumbered — same offence, now folded into a sub-section of a combined provision.
  • Changed — the provision was reworked; wording, scope or punishment differs — read the note.
  • New in BNS — no IPC equivalent.
  • Omitted — not re-enacted in the BNS.

Primary sources to verify against

  • India Code — Bharatiya Nyaya Sanhita, 2023 & IPC, 1860 (indiacode.nic.in)
  • MHA / PRS Legislative Research IPC↔BNS comparison charts
  • Devgan.in — cross-referenced bare acts with old↔new mapping
